# Word Search Puzzle: Brain Quest

A single-page, mobile-first HTML5 word finder game, ready to upload to a GitHub repository or serve with GitHub Pages.

## Included

- Touch and mouse drag word selection
- Three playable themed word-search boards
- Hint counter, timer, daily streak, level picker, and completion screen
- Store-ready icon exports: `assets/icon-512.png` and `assets/icon-114.png`
- Four 600 × 1024 store screenshots in `screenshots/`
- Amazon Developer listing copy in `AMAZON_DEVELOPER_LISTING.md`

## Publish on GitHub Pages

1. Create a repository named `word-search-puzzle-brain-quest`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save. GitHub will give you a public link to the game.

No build step or server is required. Open `index.html` locally to play.
